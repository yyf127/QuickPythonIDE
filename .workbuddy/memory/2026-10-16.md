## 阶段3 已完成（18:5x）
- 宿主 main.py 改为 subprocess 子进程执行用户代码（替代阶段1的 exec 主线程阻塞）：
  - `run_code(code, path, python)`：有 webview 窗口→异步启动子进程，stdout/stderr 经 `webview.windows[0].evaluate_js("window.appendOutput(...)")` 实时推回前端，结束推 `window.onRunFinished(ok, rc)`；返回 `{ok, async, pid}`。无窗口（测试/CLI）→退化同步执行并返回 `{ok, stdout, stderr}`（保证单测无需 GUI）。
  - `stop_code()`：`self._proc.kill()` 终止运行中的子进程，修复死循环卡死窗口的坑。
  - 子进程写临时 .py 文件 + `python -u`（-u 关闭缓冲，实时输出），读取临时文件在 _waiter 里清理。
- 新增 RPC：`python_versions()`（扫描 sys.executable / PATH / `py -0`，供版本切换下拉）、`pip_install(packages, python)`（pip install，超时600s）、`backup_file(path)`（复制为 .bak，已存在则加时间戳）。
- 前端 ui/：顶栏加 Python 版本 select（loadPythonVersions 填充）、pip 安装输入+按钮、备份按钮；停止按钮启用；runActive 改异步启动（禁用运行/启用停止），新增 stopActive/installPip/backupActive 与全局 `window.appendOutput`/`window.onRunFinished` 桥函数。
