## 重要更正：嵌入 Python 能跑 tkinter（需补 Tcl/Tk 文件）
- 先前结论"官方 embeddable 不能跑 tkinter"措辞过绝对。准确说法：**官方 embeddable zip 默认不含 Tcl/Tk 运行文件（_tkinter.pyd、tcl/ 目录、tcl*.dll、tk*.dll），所以 `import tkinter` 默认失败**；但**可以把同版本完整 Python 的 Tk 文件补进 root/<版本>/ 让它跑起来，且仍不装系统 Python**。tkinter 是标准库，**无法通过 pip install 安装**（pip 上没有 tkinter 包）。
- 用户因此决定**改回 tkinter 原生渲染**（比 webview 更"大家习惯"），放弃之前的 webview 方案（commit 344cffa）。
- 实现要点（tkinter 版 `run_form`）：
  - 宿主生成自包含 tkinter `app.py`：在 `_build()` 里按设计器布局 `tk.Button/Label/Entry/Text` 并注册到 `_widgets`；`ui.on(id, fn)` 绑定按钮 command（Entry 绑 <Return>、Text 绑 <KeyRelease>）；`ui.get/ui.set` 读写控件；尾部 `root.mainloop()`。新增**多行文本(TextArea→tk.Text)**控件。
  - 新增 RPC `check_tkinter(python)`：用 `import tkinter; Tk().withdraw(); destroy()` 真实探测（不弹窗）；`ensure_tkinter(python)` → 内部 `_ensure_tkinter`：探测失败则试图从**同 major.minor 版本、且自身 tkinter 可用**的完整 Python（受管运行时/Program Files/AppData/PATH）复制 Tcl/Tk 文件到嵌入目录（tcl/、_tkinter.pyd、tcl*.dll、tk*.dll、zlib1.dll、Lib/tkinter，并改 `._pth` 加 `.\DLLs` 与 `Lib\site-packages`）。找不到同版本源则 `need_copy=True` 并返回指引（让用户手动拷）。
  - `_resolve_python("")` 在冻结后回落到 root/ 第一个嵌入式解释器（避免用 IDE 自身跑脚本）。
  - UI：窗体设计器 palette 加「检查 Tk 环境」「修复 Tk」按钮；`runForm` 先 check_tkinter，缺失自动 ensure_tkinter，仍失败则日志给出补齐指引再 abort。
- 校验：`py_compile main.py` 通过；生成 app.py `compile` 合法且含 tkinter/控件注册/ui 桥；更新测试 `test_gen_form_tk_app` + `test_check_tkinter_on_missing`（均过）；`node --check main.js` 通过、HTML 新 id 齐全。
- 注意：真实 tkinter 弹窗 + Tcl/Tk 补齐需在用户本机用**重编译后的新 exe** 实测（沙箱无法替用户弹窗/拷 Tk 文件）。若 root/<版本>/ 没有同版本完整 Python 可复制，用户需手动下载同版本完整安装包拷 Tk 文件，或用「修复 Tk」按钮触发自动复制（前提是机器上恰好有同版本完整 Python）。

## 关键发现：tkinter-embed 可用，但必须设 TCL_LIBRARY/TK_LIBRARY
- 先前以为 `tkinter-embed`(PyPI) 不能用 —— **错**。实测它完整打包了 `_tkinter.pyd` + Tcl/Tk 运行库，只是把库放在非标路径（如 `Lib/site-packages/tcl/tcl8.6`），Tcl 默认搜不到 `init.tcl` 而报 "Can't find a usable init.tcl"。
- 修复：运行前设 `os.environ["TCL_LIBRARY"]`/`["TK_LIBRARY"]` 指向 `tcl8.6`/`tk8.6` 目录即可（已实测 `TCL 8.6 TK 8.6` → TK_OK）。因此**无需下载完整安装包 / msiexec 提取**，tkinter-embed 就是干净的在线补齐方案。
- 落实：宿主新增 `_tk_env(python_exe)`（搜索 `tcl/tcl8.6`、`Lib/site-packages/tcl/tcl8.6`、`tcl8.6` 找 init.tcl，以及对应 tk8.6 目录）；`check_tkinter`/`_ensure_tkinter`/`_ensure_tkinter_online` 的探测都带上该 env；`run_code`/`run_form` 启动子进程时把该 env 合并进 subprocess env；生成的 tkinter `app.py` 模板顶部也先设好这两个环境变量再 `import tkinter`。这样"运行窗体"和"运行含 import tkinter 的脚本"都能在嵌入解释器上直接出窗口。
- 验证：前端下载 3.11.9（含 tkinter）端到端实测通过（下载/解压/pip/tkinter-embed 均成功，import tkinter 正常）。
